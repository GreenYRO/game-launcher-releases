# Game Launcher

Installers for Game Launcher, a Windows game launcher made for a bachelor thesis and shared
with a few friends. Only the installers live here; the code does not.

**Download:** the newest `GameLauncher-Setup.exe` is on the
[latest release](https://github.com/GreenYRO/game-launcher-releases/releases/latest).

---

## Pe românește

Aici sunt doar installerele pentru Game Launcher, launcher-ul de jocuri din lucrarea mea de
licență. Codul nu e aici.

- **Prima instalare:** descarci `GameLauncher-Setup.exe` din
  [ultima versiune](https://github.com/GreenYRO/game-launcher-releases/releases/latest) și îl
  rulezi. Windows o să avertizeze că fișierul nu e semnat: „Mai multe informații”, apoi
  „Rulează oricum”.
- **Actualizare:** închizi launcher-ul și rulezi noul `GameLauncher-Setup.exe` peste cel vechi.
  Păstrează tot: jocurile, timpul jucat, coperțile alese și setările.
- Launcher-ul verifică singur, o dată pe zi, dacă a apărut o versiune nouă aici, și îți spune.
  Nu descarcă și nu instalează nimic singur.
